# Product Document

## Positioning

Enterprise Context Layer is a local-first RAG demo for teams that need source-grounded AI answers over internal knowledge. The demo focuses on file/manual ingestion, retrieval debug visibility, citations, auditability, latency, cost visibility, document cleanup, and provider switching.

## Target Users

- Founder-stage AI teams evaluating full-stack execution speed.
- Internal tool teams that need a practical AI knowledge assistant.
- Sales or customer success teams that answer repeated policy, security, onboarding, and pricing questions.

## Core Workflow

1. Seed documents are loaded into PostgreSQL with pgvector.
2. The user can load a `.md` or `.txt` file, or paste a manual memo from the frontend.
3. The user asks a question with a selected top-k retrieval depth.
4. The backend embeds the query, retrieves matching chunks, and returns citations.
5. The answer is generated by a fallback extractive provider or an LLM provider such as DeepSeek.
6. The audit log records query, citations, latency, and estimated cost.

## Demo Value

- Shows AI application architecture without hiding behind a chat UI.
- Runs locally and cheaply for screen recording.
- Demonstrates provider mechanism for embeddings and chat.
- Makes remote, async, source-grounded collaboration visible through audit logs.
- Gives the reviewer a complete interactive loop instead of a static chat screen.
- Makes retrieval quality inspectable through chunk id, source title, score, and citation preview.

## Non-Goals For The First Demo

- No production permission model.
- No SSO.
- No drag-and-drop upload queue or background worker.
- No multimodal retrieval.
- No hosted deployment requirement.
